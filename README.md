# DeSoto Auto Concierge - Client Intake Portal

Official web intake and client specification portal for **DeSoto Auto Concierge**, a Colorado-based private automotive acquisition and sales management firm.

## Features
- **Integrated Web3Forms Endpoint**: Active background transmission wired directly to `CustomerSupport@DeSotoAC.com` using access key `8665b8e6-e8df-4b63-83af-f409f360e14e`.
- **Seamless User Experience**: Submits in the background via AJAX fetch, showing the client a polished mandate confirmation screen without leaving the page.
- **GitHub Pages Ready**: Zero build steps required—just upload to GitHub root.
- **Support Contact**: Configured exclusively for `CustomerSupport@DeSotoAC.com`.

## Deployment to GitHub Pages

1. Upload `index.html` and `README.md` to the root of your GitHub repository.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
4. Test a submission on your live URL—it will immediately route to `CustomerSupport@DeSotoAC.com`.
